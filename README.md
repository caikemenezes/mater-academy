# Mater Academy

Plataforma de estudos da Mater Tecnologia: trilha de formação em engenharia de IA aplicada (9 fases, da IA à cibersegurança), aulas gratuitas do YouTube em sequência, bloco de notas por aula, entregas com checklist, timer de estudo e plano de 90 dias.

Site estático (HTML, CSS e JavaScript puro). Progresso e notas ficam no navegador; a sincronização entre aparelhos usa Supabase (configurável em Ajustes).
